# C++ Hash Table Implementation

A C++ application that demonstrates the implementation and use of a hash table. This project was developed in Microsoft Visual Studio as part of my advanced C++ coursework.

## Features

- Implements a hash table data structure in C++
- Uses hashing to organize and store data
- Demonstrates insertion and hash table management
- Uses object-oriented programming to represent and manage data
- Includes logic for determining appropriate table sizing
- Applies prime-number calculations as part of the hashing implementation

## Concepts Demonstrated

- C++
- Hash Tables
- Hashing
- Data Structures
- Object-Oriented Programming
- Classes and Objects
- Algorithms
- Data Management

## Development Environment

- C++
- Microsoft Visual Studio

## About This Project

This project was created to explore hash-based data structures and their implementation in C++. It strengthened my understanding of hashing, table organization, and the use of object-oriented programming to manage structured data.
